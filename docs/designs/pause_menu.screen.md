# Pause Menu

Mockup: mockups/index.html#pause · Mobile: landscape · Status: draft
From: In-Game HUD (Esc / pause button / Android Back) · To: HUD, Settings, System Dialogs

## Purpose
Quick options during a match. The match **keeps running** (online game).

## Elements
Wood sign `MENU`, hint "The match keeps running while this menu is open.", `Resume`, `Settings`,
`Scoreboard`, music and SFX sliders, `Leave Match` (red).

## Actions
`Leave Match` → confirmation ("You will lose this match's EXP and a bot takes your slot").
